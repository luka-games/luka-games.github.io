# Luka Games — GitHub Pages Sitesi

Bu klasör, 5 Android oyunun ortak **`app-ads.txt`** doğrulama dosyasını ve her oyunun **Gizlilik Politikası** sayfasını barındırmak üzere hazırlanmıştır.

## Yayınlama Adımları (GitHub Pages)

1. `luka-games` GitHub hesabında **`luka-games.github.io`** adında herkese açık (Public) bir depo oluşturun *(kök alan adı kullanmak `app-ads.txt` dosyasının `https://luka-games.github.io/app-ads.txt` adresinde çalışması için gereklidir)*.
2. Bu klasörün (`luka-games-site`) içindeki tüm dosya ve klasörleri (`index.html`, `app-ads.txt`, `privacy.html`, `privacy/`, `assets/`) o deponun köküne yükleyin.
3. GitHub repo **Settings → Pages** bölümünde kaynağın `main` (root `/`) olarak aktif olduğunu doğrulayın.
4. Yayına çıktıktan sonra aşağıdaki adresleri test edin:
   - `https://luka-games.github.io/app-ads.txt`
   - `https://luka-games.github.io/privacy/kulfeneri.html`
   - `https://luka-games.github.io/privacy/altinkovan.html`
   - `https://luka-games.github.io/privacy/golgelabirent.html`
   - `https://luka-games.github.io/privacy/sonokcu.html`
   - `https://luka-games.github.io/privacy/guneskosusu.html`
